💾 Histórias e backup
Carregar histórias do GitHubAo abrir o site, buscar o arquivo historias.json do repositório.
Exportar gera o arquivo historias.json. Se você subir esse arquivo no repositório do GitHub, as histórias aparecem em qualquer celular que abrir o site.
Isso salva um token do GitHub neste celular. Use um token fine-grained com permissão de Contents: Read and write apenas neste repositório. Se preferir não mexer nisso, use o Exportar/Importar acima — funciona igual.
⚡ Velocidade da voz (áudio guardado)
Cada trecho de voz gerado fica guardado neste aparelho. Repetir uma história, voltar um trecho ou ouvir de novo amanhã não gasta a cota outra vez — o site usa o áudio guardado. E funciona sem internet.
